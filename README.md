# 🎬 MovieGo

A modern and interactive **Movie Ticket Booking Website** built using **HTML, CSS, and JavaScript**.
MovieGo allows users to select movies, watch trailers, choose seats, switch themes, and simulate ticket booking in a sleek cinema-style interface.

1. Select your movie

3. Choose date & showtime
4. Select seats
